# Note CLI (intro-node-v3)

A small Node.js command-line notes app used for learning Node basics. It supports creating, listing, finding, removing notes and an optional web view.

## Current functionality

- Add a note: `note-cli add "My note" -t tag1,tag2`
  - Creates a new note with sequential numeric `id` (1, 2, 3, ...).
  - Tags are optional; pass `-t` or `--tags` with a comma-separated list.
- List all notes: `note-cli all`
  - Prints a table with `id`, `content`, and `tags`.
- Find notes: `note-cli find <filter>`
  - Case-insensitive search against `note.content`.
- Remove a note by id: `note-cli remove <id>`
  - Accepts numeric or string ids (comparison is tolerant).
- Web view: `note-cli web [port]`
  - Starts a simple web server that renders all notes into an HTML template.
- Clean all notes: `note-cli clean`
  - Removes all notes from `database.json`.

Notes about IDs and behavior

- New note IDs are generated sequentially. The implementation inspects existing note IDs:
  - If existing "small" numeric IDs are present, it continues from `maxId + 1`.
  - If only legacy (large timestamp) IDs exist, new notes fall back to `notes.length + 1`.
- Deletion (`remove`) coerces both sides to strings, so calling `note-cli remove "1"` or `note-cli remove 1` behaves the same.

## Files of interest

- `index.js` – CLI entry (registered as `note-cli` in `package.json`).
- `src/command.js` – CLI command definitions (yargs). Connects commands to the notes functions and the web server.
- `src/notes.js` – Core notes logic (create, list, find, remove, removeAll). Reads/writes `database.json` via `src/db.js`.
- `src/db.js` – File-based persistence using `database.json`.
- `src/utils.js` – Console display helper (`DisplayNotes`) used by the `all` and `find` commands.
- `src/server.js` & `src/template.html` – Web server and template used by the `web` command.

## JS files not related to note-cli logic

These files in the repo are not part of the note-cli functionality (examples / demos / standalone servers):

- `fs_read.js` — Demo script that reads `package.json` and writes `output.txt`. Not used by the CLI.
- `server.js` — Root-level simple HTTP server (returns "Hello, World!") — separate from the `src/server.js` used by the CLI's `web` command.

(Other JS files in `src/` are part of the CLI. Tests live under `tests/` and relate to the notes code.)

## Install & run

Install dependencies:

```bash
npm install
```

Run the CLI (local):

```bash
node index.js <command> [options]
```

Or use the installed bin (after `npm link` or `npm install -g`):

```bash
note-cli add "My note" -t tag1,tag2
note-cli all
note-cli find test
note-cli remove 1
note-cli web 4000
```

## Running tests

The project uses Jest. Run tests with:

```bash
npm test
```

If you run into test failures related to `getDB` mocking, ensure tests mock `getDB` to return an object with a `notes` array (e.g. `getDB.mockResolvedValue({ notes: [] })`) or the implementation handles a missing/undefined DB object (the current code uses fallback defaults).
